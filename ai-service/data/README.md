# Dataset Instructions

To run the model training, you must download the Kaggle Credit Card Fraud Detection dataset.

1. Go to: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
2. Download `creditcard.csv`
3. Place `creditcard.csv` in this directory (`ai-service/data/`)

The application expects `ai-service/data/creditcard.csv` to exist for the initial training pipeline.
